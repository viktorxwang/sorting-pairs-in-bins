# sorting-pairs-in-bins
Scripts that I used to tackle the open problem "Sorting Pairs in Bins" from the 2003 book by Winkler. It is a combinatorial problem, and research is currently going with C++ scripts.

I was inspired to research an open problem in Winkler's from a similar 2025 paper "The Most Malicious Maitre'D" by Madharavpu. The goal of this project is to assess the boundaries of current computational methods for analyzing "Sorting Pairs in Bins" and identify proven and open lemmas.
